Safety Model
------------
Default behavior is safe:
- dry_run=True by default
- no live MIDI messages are sent unless --live is provided
- live mode requires an output port that matches --allow-output
- SysEx is blocked unless explicitly enabled in code/config
- SysEx payload size is bounded by config
- project saves are atomic
- existing project files are backed up before overwrite
- project paths must remain inside the configured project root
- tests do not require hardware

Safe live-send example for a future setup:
.venv\Scripts\python.exe ko2_sampler_daw\run_ko2_daw.py --live --allow-output "KO II" --output-port "KO II MIDI" --note 60
