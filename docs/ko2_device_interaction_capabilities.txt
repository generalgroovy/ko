Practical Conclusions
- Direct USB-C MIDI is the correct route on this machine when EP-133 appears as both input and output.
- The app can send pad triggers, transport start/stop/continue, clock ticks, CC 1 fader output, bank select, program change, panic messages, and read-only device file browsing over the confirmed EP-133 route.
- Full read-only snapshots preserve node/path/size metadata and a canonical SHA-256 inventory hash for before/after integrity checks.
- Selected sounds can be downloaded, CRC-verified against device metadata, converted to WAV, viewed as a waveform, and previewed locally without a device write.
- The stable Scene Arranger can sequence all 48 KO II pad notes, automate MIDI CC, record armed groups, follow or generate clock, and export editable projects/MIDI without writing device storage.
- Completed project archive downloads are inspected in memory and mapped to group/pad sound assignments without extracting archive members. Opaque records receive hashes and can be diffed by exact byte range.
- The current 9/9 project catalog has aggregate content/structure SHA-256 dd8093f1f9edd327ebc4a4be9cf33b7cbad83666dc0571b3b6f5a1f5399290f6.
- Native audio capture and timeline edits are local-only and do not write EP-133 storage.
- SysEx responses are matched by request id and command because the EP-133 can emit unrelated firmware diagnostic messages.
- A GET init must be followed by every declared data page. Abandoning a manual GET can leave the device file service returning `err lfs 6327 2_0_5` until reconnect/power-cycle.
- The device does not expose a generic query for the current playing scene, selected pad, selected effect, complete project state, or current front-panel mode through the tested public MIDI/SysEx surface.
- Pause is not a distinct standard MIDI transport command. The available controls are Start, Continue, and Stop. The app should label this as transport Start/Continue/Stop rather than DAW-style play/pause.
- File and sample upload/delete/move/metadata writes must stay blocked until a backup/restore workflow is fully verified.
